# Portafolio de Gabriel Yaraure

Portafolio personal hecho con **HTML, CSS y JavaScript puro** (sin frameworks ni backend).

## Estructura

```
portafolio/
├── index.html        → estructura y contenido
├── css/
│   └── styles.css    → diseño (tema oscuro)
├── js/
│   └── main.js       → interactividad
└── README.md
```

## Cómo verlo en tu computadora

Abre `index.html` con doble clic. No necesita instalar nada.

## Qué puedes personalizar después

- Los enlaces `#` de "Ver detalles" en cada proyecto, cuando tengas capturas o enlaces.
- Las descripciones de los certificados (institución, año, enlace de verificación).

## Publicación

1. Subir la carpeta a un repositorio de GitHub.
2. Importar el repositorio en [Vercel](https://vercel.com) (proyecto estático, sin configuración extra).
3. Cada vez que hagas `git push`, Vercel actualiza la página automáticamente.
